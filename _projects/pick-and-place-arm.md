## Goal

Build a simulated robot arm that finds objects with a camera and picks them up, to learn the core robotics software stack:
perception, inverse kinematics and motion planning.

## Plan

1. Set up ROS 2 and simulate an arm in Gazebo.
2. Use MoveIt to plan and execute motions to target poses.
3. Add a simulated camera and an OpenCV node to detect objects and estimate their positions.
4. Connect detection to motion planning for a full pick-and-place cycle.
5. Measure success rate and cycle time.
